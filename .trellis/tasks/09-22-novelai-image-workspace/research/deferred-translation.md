# Translation options (deferred from MVP)

Earlier research found that `argosopentech/argos-translate` is an MIT-licensed
offline Python library with Chinese and English support, while
`LibreTranslate/LibreTranslate` is an AGPL-licensed self-hosted API built on
Argos. Both avoid proprietary translation API calls, but Argos uses OpenNMT
neural machine-translation models and was excluded by the memory constraint.
Apertium is rule-based, but no mature direct Chinese-English pair was found in
its official repositories.

`ffdkj/ffdkj-Danbooru_Tag-Chinese-English-Translation-Table` is an
MIT-licensed candidate for low-memory *tag lookup*: it publishes an
approximately 24 MB SQLite database with roughly 329,000 English/Chinese
Danbooru tag pairs. It performs no runtime model inference, but its README
states that translations were initially generated by Gemini and then
human-corrected. It supports tag/short-phrase lookup, not free-text sentence
translation.

Translation is out of scope for this workspace MVP. Do not wire any of these
projects into the product without a new requirements decision.
